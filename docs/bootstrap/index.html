AcTweeteR para Kodi

Bootstrap oficial de AcTweeteR 0.4.18 para Kodi 21.3 Omega.

Instala este archivo ZIP desde Kodi:

repository.actweeter-1.0.3.zip

Después de instalar el ZIP, abre Instalar desde repositorio → AcTweeteR Repository para instalar la skin 1.2.16 y el servicio 0.4.18. Kodi resuelve las dependencias desde sus repositorios y los repositorios upstream agregados. XStream Pro 1.1.2.1 se distribuye bajo CC BY-NC 4.0 y solo puede utilizarse de forma no comercial.

La instalación limpia, actualización y ejecución de la corrección de Continuar viendo de 0.4.18 aún no están validadas en runtime en Apple TV/tvOS ni en otros sistemas. Sigue abierta una incidencia crítica de cierre de Kodi; el propietario autorizó el riesgo para este release únicamente. Consulta las instrucciones de instalación y las notas y limitaciones.
