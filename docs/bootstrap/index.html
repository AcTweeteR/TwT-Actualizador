AcTweeteR para Kodi

Bootstrap oficial de AcTweeteR 0.4.17 para Kodi 21 Omega.

Instala este archivo ZIP desde Kodi:

repository.actweeter-1.0.3.zip

Después de instalar el ZIP, abre Instalar desde repositorio → AcTweeteR Repository para instalar la skin 1.2.15 y el servicio 0.4.17. Kodi resuelve las dependencias desde sus repositorios y los repositorios upstream agregados. XStream Pro 1.1.2.1 se distribuye bajo CC BY-NC 4.0 y solo puede utilizarse de forma no comercial.

La instalación limpia de 0.4.17 y su ejecución en Apple TV/tvOS aún no se han validado. Consulta las instrucciones de instalación y las notas y limitaciones.
