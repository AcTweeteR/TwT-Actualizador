AcTweeteR para Kodi

Bootstrap oficial de AcTweeteR 0.4.21 para Kodi 21.3 Omega.

Instala este archivo ZIP desde Kodi:

repository.actweeter-1.0.3.zip

Después de instalar el ZIP, abre Instalar desde repositorio → AcTweeteR Repository para instalar la skin 1.2.18 y el servicio 0.4.21. Kodi resuelve las dependencias desde sus repositorios y los repositorios upstream declarados. XStream Pro 1.1.2.2 se distribuye bajo CC BY-NC 4.0, con atribución y modificaciones indicadas, para uso no comercial.

Trakt es opcional. Consulta las instrucciones de instalación y las notas y limitaciones.

Las pruebas automatizadas y de integridad pasaron; la instalación y funciones en runtime aún no se han validado en las plataformas objetivo. Sigue abierta la incidencia crítica de cierre de Kodi; el propietario aceptó este riesgo para 0.4.21 únicamente.
