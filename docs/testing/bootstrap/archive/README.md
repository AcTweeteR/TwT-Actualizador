# Historical AcTweeteR Testing repository installers

This directory is for old Testing repository installer ZIPs. Do not use it for new Kodi installations.

The normal bootstrap directory lists only the latest repository installer and a link to this archive. The original versioned URLs remain available in the parent directory to preserve backward compatibility; historical ZIP hashes must match the originals.

This archive does **not** contain archived skin, Service, or XStream releases. Those are versioned packages in the Testing feed.
