# AcTweeteR

AcTweeteR is a locally maintained Kodi skin derived from BINGIE Matke 2.0.2.
The upstream UI and required notices remain intact; AcTweeteR-controlled
portable provider-only menu/widget defaults are maintained separately in this
source tree. XStream availability, provider credentials, and user state remain
device-local and are not included. See `UPSTREAM_NOTICES.md` and
`fonts/OFL.txt` for provenance and font licensing.
