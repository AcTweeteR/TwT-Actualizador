# repository.actweeter 1.0.2

Kodi's native repository bootstrap add-on for AcTweeteR. It exposes the AcTweeteR
catalog, the live Omega index from Matke BINGIE, and the live SlyGuy add-on index.
Kodi's own resolver installs dependencies from their declared catalogs; the
SlyGuy packages continue to download from the author's own datadir. XStream Pro
is separately included unchanged in the private candidate's main catalog under
its CC BY-NC 4.0 terms; do not redistribute that component commercially.

The AcTweeteR index and all releases are built and published manually only after
explicit owner authorization. This build does not upload or publish anything.
See the repository changelog for the live-upstream metadata change.
