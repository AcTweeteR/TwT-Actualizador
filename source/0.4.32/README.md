# AcTweeteR unified Mac/Lenovo Beta source candidate

## Candidate: service 0.4.44 / skin 1.2.30~beta2 / XStream Pro 1.1.2.10

This candidate combines the profile-safe Beta initialization with the
Mac-confirmed manual trailer actions for movies and TV shows, preserves the
Lenovo automatic-preview guards and series-change tracking, and stops the
service from changing Kodi's global add-on update preference. It is not
published or installed. Stable, the installed Mac Master, and Lenovo are
unchanged by this source candidate.

XStream remains based on the pinned 1.1.2 upstream source and CC BY-NC 4.0
attribution. Its package build now validates the premium route's provider
catalog baseline hook in addition to the `series_recent` provider.

## Current service: 0.4.39 (installer Beta)

The service recognizes both installed AcTweeteR repository channels for native
installation/repair. SlyGuy and InputStream Adaptive remain optional. Existing
wizard state and provider settings are preserved. Build using
`python3 source/0.4.32/tools/build_service_package.py`; publish only the new
service ZIP in the Testing feed. The published skin 1.2.29~beta10, XStream
1.1.2.8 and repository Testing 1.0.1 are reused without rebuilding or replacing
their immutable artifacts. No Stable publication is authorized.

The sections below describe historical Beta 10/11 development, not current
installer runtime acceptance. tvOS installation and playback require device
evidence; successful unit tests do not establish that result.

The next Beta candidate contains skin `1.2.29~beta10` and service `0.4.37`.
It preserves the Beta 9 backed-up, versioned Skin Shortcuts migration for the
Beta 8 main and power menu defaults. Only previously tracked or byte-identical
known Beta 8 defaults are updated; customized profile files are preserved and
reported as conflicts. Beta 10 additionally makes the lower power actions
reachable from the last main-menu entry using D-pad navigation; other main-menu
entries retain their existing route to Home content. The candidate still
requires runtime acceptance. Stable packages and the Stable index remain
unchanged.

This source snapshot is based on official `main` at commit
`267dcad96074a4f3a70a8148492f4072d1d0fbc3` (Beta 9 merge).
The 0.4.32 candidate failed on Lenovo because six inactive defaults did not
have generated identities. The 0.4.33 base corrected that and contains a service
migration for Skin Shortcuts 2.0.3 that resolves widget identities from native
generated includes, persists four-field custom-property records for currently
materialized shortcuts, and performs a second native build before validating
`widgetExpandable` in the active XML. Defaults absent from the current build
are deferred; active expandable widgets remain a hard validation gate.

The service candidate is `service.actweeter` 0.4.37; it retains the
0.4.33 property migration and session-scoped coalescing. The skin is
candidate `1.2.29~beta10`. Repository 1.0.3 and XStream Pro 1.1.2.7
remain byte-identical to the 0.4.31 official packages. This snapshot does not include Kodi profile data or
generated per-user menu caches.

`overrides.xml` `<propertydefault>` is intended to initialize defaults when
Skin Shortcuts creates a default shortcut. AcTweeteR widgets on existing
profiles are user-owned shortcut records, and their actual `group` and
`labelID` are generated by Skin Shortcuts. Therefore the migration first asks
Skin Shortcuts to build, reads those runtime identities, appends only missing
four-field rows to the profile property store, then requests and verifies a
second build. This avoids replacing custom shortcuts or relying on localized
labels/default IDs as property keys. It also avoids failing a user's build on
defaults from groups that Skin Shortcuts did not materialize for that profile.

Static/unit tests and reproducible package checks are not runtime proof. Beta
9 has been installed from the official Testing feed. Runtime validated the
migrated main-menu destinations and Home/widget loading; the lower action list
was visible but not D-pad reachable. Beta 10 is a Testing-only skin update to
close that navigation gap. No Stable publication is part of this candidate.

## Build

Use Python 3 and the standard library. Build the service from this directory:

```sh
python3 tools/build_service_package.py --output /tmp/service.actweeter-0.4.37.zip
```

The distribution index builder accepts the 0.4.37 service ZIP together with
the unchanged 0.4.31 skin, repository and XStream ZIPs. Candidate output must
remain separate from the official stable feed until all gates pass.
